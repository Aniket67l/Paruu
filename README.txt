A LITTLE UNIVERSE CALLED PARI — birthday website
================================================

FILES
- index.html: complete responsive birthday website
- assets/: photos used by the website

PREVIEW
Open index.html in Chrome or Edge.

HOST ON NETLIFY
1. Keep index.html and the assets folder together.
2. Open Netlify and sign in.
3. Choose the manual deploy option.
4. Upload the full folder contents (index.html plus assets folder) or drag the ZIP file.
5. Wait for the public deployment URL and test it on mobile before sharing.

UPDATES IN THIS VERSION

- Added floating balloons and confetti.
